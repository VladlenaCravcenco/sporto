# Проверка каталога и SEO — 2026-10-08

Статус: локальный аудит и исправления выполнены; production-приёмка не завершена. Изменения не развёрнуты.

## Исправлено

- Proxy передаёт язык в request headers: root layout получает правильный HTML lang и preload кириллицы. Заголовок сохраняется при обновлении auth cookies.
- Каталог, меню, слайдер, canonical и страницы товара используют общий генератор ссылок с существующей транслитерацией RU/RO. Старые slug перенаправляются на canonical через 308. Убрано повторное decodeURIComponent параметра маршрута, которое могло вызвать 500 для процента в slug.
- Product JSON-LD экранирует `<`, чтобы описание не могло закрыть script.
- Убран повтор SPORTO в title каталога (бренд добавляет root template).
- Пагинация имеет собственный canonical. Поисковые/фильтрованные выдачи получают noindex,follow; canonical и hreflang сохраняют фильтры, исключают сортировку. Это консервативная политика до создания отдельных SEO-посадочных категорий.
- Добавлен Next /sitemap.xml с RU/RO alternates: основные информационные страницы и активные товары, все порции по 1000 с устойчивой сортировкой. При ошибке БД не публикуется обрезанный sitemap. Старый api/sitemap.ts остаётся для legacy-приложения.

## Проверено

- npm run next:build: успешно, TypeScript и /sitemap.xml в манифесте маршрутов.
- catalog-seo.cjs: product URLs, canonical пагинации, фильтры/noindex, hreflang, title, передача языка и sitemap с 1001 товаром.
- catalog-rpc.cjs: фильтры, локализованные facets, количество, выход за страницы, поиск, ошибки RPC; обновлён тестовый loader под существующую search-history зависимость.

- product-gallery.cjs и responsive-images.cjs: взаимодействия галереи и выбор размеров изображений, без браузерного рендера.

- Live HEAD /ru/catalog: HTTP 200, X-Robots-Tag: noindex,nofollow (ожидаемо для staging IP).

## До запуска

1. Полная проверка браузером на сервере: комбинации фильтров, RU/RO, корзина/варианты, мобильная навигация, реальные ответы 404. Повторный live GET разрешён пользователем: HTML выборочных страниц проверен, полная браузерная приёмка ещё нужна.
2. Legacy URLs (/catalog, /product/..., ?lang=ru и др.) не покрыты системными перенаправлениями Next. Составить карту 301/308 до переключения DNS.
3. Catch-all информационных страниц и брендов пока не экспортирует generateMetadata. Legacy Helmet не заменяет гарантированные серверные metadata Next. Нужны canonical/hreflang/title/description и проверка 404 неизвестного бренда. Бренды пока намеренно не включены в новый sitemap.
4. На основном домене проверить HTTPS, canonical domain, robots.txt и убрать staging X-Robots-Tag только для production host. Сейчас public/robots.txt указывает https://www.sporto.md/sitemap.xml.
5. После деплоя проверить sitemap с реальной БД, Product JSON-LD и SEO HTML. Передать sitemap поисковикам после открытия индексации.
