## Подготовлено локально

- src/database/2026-10-08_search_substring_matches.sql убирает ранний выход, сохраняя существующие trigram indexes и ранжирование. Точный SKU остаётся первым, остальные совпадения доступны. Подсказки ограничены 8, каталог — 24 на страницу. SQL ещё требует выполнения в Supabase; прямого SQL-доступа в сессии нет.
- Next links/router для header, home, footer, cards, pagination, search и встроенного legacy router. Legacy ProductCardView по умолчанию сохраняет anchor, Next передаёт свой компонент ссылки.
- Bulk prefetch отключён, чтобы меню с большим числом ссылок не создавало лишние запросы.
- Loading boundary для публичных переходов; меню закрывается после выбора ссылки; поисковая строка синхронизируется с URL.

## Проверка и ограничения

- next-navigation.cjs проверяет вызовы Next router и сохранение языка/query, без браузерного рендера.
- catalog-seo.cjs, catalog-rpc.cjs, smart-search.cjs проходят.
- Для итоговой приёмки нужны SQL migration, деплой, реальное сравнение поиска 999 и браузерные замеры переходов. Не заявляем, что все причины медленной работы устранены.
