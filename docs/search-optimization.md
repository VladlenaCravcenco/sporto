# Поиск каталога

Подсказки и выдача работают через PostgreSQL RPC. Сервер не загружает весь каталог для поиска: подсказки возвращают до 8 карточек, полная выдача — до 24 товаров на странице.

Поддерживаются названия RO/RU, код и артикул, синонимы, опечатки, фильтры и пагинация. Точное совпадение кода имеет приоритет. Индексы обновляются PostgreSQL при сохранении товара.

Деплой проверяет доступность нужных RPC до переключения сервиса. Если функции отсутствуют или новая версия не проходит проверки каталога/поиска, публикация останавливается либо возвращается предыдущий релиз. Исторические SQL вынесены из репозитория; для восстановления функций нужен их архив или проверенная миграция.

После изменения поиска проверьте код товара, названия на двух языках, опечатку, запрос без результатов, страницу 2 и сочетание поиска с фильтрами. Производительность сравнивайте на одинаковых запросах с учётом кэша.
